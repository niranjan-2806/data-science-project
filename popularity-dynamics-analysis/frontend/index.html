Machine Learning Methodology & Mathematical Design

1. Why Scale Normalization Before Clustering?

View counts vary across channels by multiple orders of magnitude (5k to 120k). Without Z-score standardization z(t) = (views(t) - mean) / std, standard Euclidean distance would group videos solely by volume rather than trajectory shape. Normalization ensures a 5,000-view viral clip and a 100,000-view viral clip map to the same shape cluster.

2. Why Constrained Regression for Forecasting?

With N = 48 items, high-capacity models (deep neural nets or boosted trees) will severely overfit the small sample. A regularized linear/ridge regression trained strictly on early signals (days 0–6) provides stable parameter shrinkage, yielding a reliable test set MAPE below 35% without data leakage.

3. Rule-Based Dynamic Cluster Labeling

Cluster names are not hardcoded. The pipeline inspects centroid mechanics (peak day, late bimodal resurgence, and early surge slope) to auto-label clusters into Slow-Burn Sleeper, Viral Spike, Steady Decay, and Resurgent Wave.
